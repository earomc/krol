# krol
A Rust reimplementation of Minecraft protocol version 5 and 47 (1.7-1.8.x) server (refer to https://minecraft.wiki/w/Protocol_version#List_of_protocol_versions)

Plugin support:
- Rust Plugin API as similar as possible to the Bukkit API (Bukkit 1.8.8). 
- Compatibility layer implemented to support Java Bukkit API plugins for version 1.8.8. The compatibility layer needs to have expose the exact same API as the original Bukkit 1.8.8 API.
